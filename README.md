# 🧠 Tiny LLaMA AI Chatbot

An interactive AI chatbot built using the [Tiny LLaMA API](https://github.com/jquesnelle/tiny-llama) to simulate real-time, multi-turn conversations. Lightweight, fast, and deployable with a minimal interface.
---

## 🛠️ Tech Stack

- 🐍 [Python](https://www.python.org/)
- 🧠 [Tiny LLaMA API](https://github.com/jquesnelle/tiny-llama)
- 🎛️ [Streamlit](https://streamlit.io/) *(or [Gradio](https://www.gradio.app/) if used)*
- 🐙 [GitHub](https://github.com/)

---

## ✨ Features

- 🔄 Real-time multi-turn AI conversations  
- 💬 Context-aware responses with a minimal footprint  
- 🖥️ Simple and interactive web interface  
- ⚡ Fast and lightweight, ideal for local and low-resource usage
